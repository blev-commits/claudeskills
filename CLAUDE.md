# CLAUDE.md

Configuration-only repository: vendored Claude Code skills, shared hook config,
and plugin settings. No build, no tests, no CI. See `README.md` for the layout
and the skill inventory.

## Pull requests

The repository owner has given standing authorization to merge their pull
requests without asking first. Recorded 2026-09-17 at their request.

Scope:

- Applies to PRs opened in repositories the owner owns.
- Merge once the PR is mergeable and CI, if any, is green.
- Use the repository's existing merge convention — this repo uses merge commits,
  not squash or rebase.
- When landing a PR that has an unresolved review thread or a changes-requested
  review, say so in the reply rather than letting it pass silently.

Not covered: approving PRs, merging PRs authored by other people, and
force-pushing to branches someone else created.
